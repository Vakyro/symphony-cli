# Symphony

Runtime local en Rust que coordina los CLIs oficiales de IA para código (Claude Code, Codex, Antigravity, Kimi Code, Copilot) desde una sola terminal. Idea central: **AGENTE ≠ MODELO**. Si un proveedor se queda sin cuota, el agente pasa a otro sin volver a explicar la tarea.

**Estado:** en construcción. Todavía no hay nada usable.
